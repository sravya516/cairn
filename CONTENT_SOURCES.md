# Cairn — Content Sources Register

This file tracks every authoritative source used for Cairn's emergency content, which guide(s) rely on it, and when it was last verified.

## Honesty policy (read first)

- Guides are **original explanations** written from general knowledge of the public guidance published by the organizations below. They are not copied from those sources and **have not been professionally reviewed**.
- **"Last verified" means a person opened the live source page and compared it with the guide on that date.** It is never filled in automatically and is never guessed. `—` means *not yet verified*.
- Numbers that could cause harm if wrong (bleach drops per gallon, boil times, CPR rates, generator distances, temperature thresholds) are flagged in the "Safety-critical values" table below and must be verified first.
- Official instructions from local authorities, 911 dispatchers, and a medical professional always take precedence over this app.

## How to verify a row

1. Open the source URL while online.
2. Compare the claim in the listed guide against it.
3. If it matches, set the date (YYYY-MM-DD) and your initials. If not, fix the guide first, then record the date.
4. Run `npm test` — the test suite checks that every source ID used in a guide appears in this file.
